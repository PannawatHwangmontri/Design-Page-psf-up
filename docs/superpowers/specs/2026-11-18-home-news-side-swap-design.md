# หน้าแรก: คลิกข่าวด้านข้างแล้วเปลี่ยนข่าวเด่น

## เจตนา
ในคลิปอ้างอิง (หน้า /news) คลิกรายการข่าวฝั่งขวาแล้วรูปข่าวใหญ่ฝั่งซ้ายเปลี่ยน โดยรูปใหม่เลื่อนเข้ามาซ้อนรูปเดิม ทำให้หน้าแรกทำแบบเดียวกัน

## ขอบเขต
- ทำเฉพาะหน้าแรก (`PsfSite.tsx` ส่วนข่าว) ไม่แตะหน้า `/news`
- ไม่เพิ่ม library

## Approaches
1. **เลือกแล้ว:** state `top` เก็บลำดับข่าวเด่น รายการขวาเป็นปุ่ม กดแล้วตั้ง `top` ใหม่ ข่าวเด่นเป็นลิงก์ไปหน้ารายละเอียดเหมือนเดิม และเอฟเฟกต์เป็น CSS keyframe `news-swap`
2. ใช้ไลบรารี carousel: ไม่เลือก เพิ่ม dependency สำหรับแค่หนึ่งส่วน
3. ใช้ View Transition API (เหมือนการ์ดข่าวกับ dialog ที่มีอยู่): ไม่เลือก ต้องผูกชื่อ transition กับแต่ละรูป ซับซ้อนกว่าที่คลิปต้องการ

## การออกแบบ
- `sorted` = ข่าวเรียงใหม่สุดก่อน, `cur` = `top % sorted.length`
- ข่าวเด่น = `sorted[cur]`, รายการขวา 3 ชิ้น = ข่าวถัดไปแบบวนรอบ (`cur+1 … cur+3`)
- คลิกรายการขวา `i` → `setTop((cur + 1 + i) % sorted.length)`
- `key={lead.id}` ที่ลิงก์ข่าวเด่นทำให้ React mount ใหม่ทุกครั้ง animation จึงเล่นซ้ำ
- เอฟเฟกต์: เลื่อนเข้าจากซ้าย 8% พร้อม fade 0.6 วินาที, ปิดด้วย `prefers-reduced-motion`

## ข้อจำกัดที่รู้
- คลิปเปลี่ยนแบบซ้อนทับกรอบ ผมประมาณด้วยเลื่อน+fade เพราะดูจากเฟรมที่ 4 fps เท่านั้น ถ้าต้องการให้เหมือนมากขึ้นต้องดูคลิปละเอียดกว่านี้
- กดรายการขวาไม่ไปหน้าข่าวแล้ว ไปได้จากข่าวเด่นหรือ "ดูทั้งหมด"
- ข้อความไม่มีเพิ่ม ไม่ต้องแก้ `content.ts`

## ที่ตัดสินใจเอง
- ทิศทางเลื่อนจากซ้าย, ระยะเวลา 0.6 วินาที, ใช้ข่าวเรียงตามวันที่เหมือนเดิม
