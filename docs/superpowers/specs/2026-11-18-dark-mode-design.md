# โหมดมืด / โหมดสว่าง

## เจตนา
ผู้ใช้อยากมีโหมดมืดคู่กับโหมดสว่าง

## ขอบเขต
- ทั้งเว็บ (หน้าแรกและหน้าภายใน)
- ไม่เพิ่ม library

## Approaches
1. **เลือกแล้ว:** ปุ่มสลับในแถบเมนูบน จำค่าที่เลือกไว้ใน localStorage (`psf-theme`) ถ้ายังไม่เคยเลือก ตามการตั้งค่าของเครื่อง
2. ตามเครื่องอย่างเดียว: ไม่เลือก ผู้ใช้สลับเองไม่ได้
3. ปุ่มอย่างเดียวไม่ตามเครื่อง: ไม่เลือก

## การออกแบบ
- ค่าสีทั้งหมดเป็น token ใน `globals.css` (`@theme`) ชุดมืดเขียนทับชื่อเดิม ทำให้คลาส Tailwind เดิมใช้ได้ทันที
- `data-theme` บน `<html>` เป็นตัวสลับ: `dark` / `light` / ไม่มีค่า (ตามเครื่อง)
- สคริปต์เล็กใน `<head>` ของ `layout.tsx` อ่านค่าที่จำไว้ก่อนวาด กันการกระพริบ
- `ThemeToggle.tsx` ใช้ `useSyncExternalStore` อ่านสถานะ และส่งเหตุการณ์ `psf-theme-change` เมื่อสลับ
- ข้อความป้ายปุ่มอยู่ใน `content.ts` (`theme.toDark`, `theme.toLight`)

## ข้อจำกัดที่รู้
- สีที่ฝังตรงในคลาส (เช่น `text-white` บนปุ่มม่วง, พื้นฮีโร่ `bg-forest`, เงาหัวเว็บ) ไม่เปลี่ยนตามโหมด
- ยังไม่ได้ไล่ดูทุกหน้าด้วยตา ต้องเปิดเบราว์เซอร์ตรวจ

## ที่ตัดสินใจเอง
- สีมืดเป็นโทนน้ำตาลเข้มตามโทนเดิม (ไม่ใช่ดำสนิท) และม่วงสว่างขึ้นเพื่อให้อ่านได้บนพื้นมืด
