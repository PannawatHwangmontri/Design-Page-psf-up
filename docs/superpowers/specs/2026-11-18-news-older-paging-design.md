# ข่าวเก่ากว่า: แบ่งหน้ารายการข่าวด้านขวา (หน้าแรก)

## เจตนา
ในส่วน "ข่าว / กิจกรรม" ของหน้าแรก `/th` `/en` ผู้ใช้ต้องการไล่ดูข่าวเก่าในกล่องเดิมได้ โดยรายการด้านขวาเรียงจากใหม่ไปเก่า (บนลงล่าง) เสมอ

## เป้าหมาย
- รายการด้านขวาโชว์ทีละ 3 ข่าว เรียงวันที่ใหม่ → เก่า
- ปุ่ม "ดูเพิ่มเติม" ใต้รายการ: แสดง 3 ข่าวถัดไปที่เก่ากว่าและยังไม่ได้แสดง (แทนที่รายการเดิม)
- ปุ่ม "ย้อนกลับ": กลับไปชุดก่อนหน้า
- กดข่าวด้านขวา: ข่าวนั้นขึ้นเป็นข่าวหลักด้านซ้าย (พฤติกรรมเดิมคงไว้)

## ไม่ใช่เป้าหมาย
- ไม่เปลี่ยนหน้า `/news` และไม่เพิ่มการค้นหา/กรอง
- ไม่ทำเลื่อนต่อเนื่อง (infinite scroll) และไม่ใส่ animation ใหม่

## ข้อจำกัด
- แก้เฉพาะ `src/components/PsfSite.tsx` กับข้อความใน `src/data/content.ts` (ห้ามฝังข้อความในคอมโพเนนต์ ต้องมี TH และ EN)
- ข้อความใหม่ต้องเข้ากับตัวแก้ไขเนื้อหา `/admin` (ดู `src/data/admin-schema.ts` และค่าเริ่มต้นใน `src/lib/defaults`)
- ใช้ token และ class เดิม ปุ่มสูงอย่างน้อย 44px ใช้งานด้วยคีย์บอร์ดได้

## ทางเลือกที่พิจารณา
- **A แบ่งหน้า (เลือก)**: ความสูงกล่องคงที่ ลำดับตามเวลา ใช้ง่ายบนมือถือ
- B กล่องเลื่อนได้: เลื่อนซ้อนกับหน้าเว็บ มือถือใช้ยาก
- C ปุ่มดูเพิ่มต่อท้าย: รายการยาวเกินข่าวหลัก เลย์เอาต์เสียสมดุล

## การออกแบบ (ตามที่ตกลง)
- รายการขวา = ข่าวทั้งหมดเรียงใหม่→เก่า **ยกเว้นข่าวหลักด้านซ้าย** ไม่วนรอบอีก: เมื่อสลับข่าวหลัก ข่าวที่เคยเป็นหลักกลับไปอยู่ตำแหน่งตามวันที่
- สถานะ `page` (เริ่ม 0) เลือกชุด 3 ข่าว: `list.slice(page*3, page*3+3)` เมื่อข่าวหลักเปลี่ยนให้ปรับ `page` ไม่ให้เกินจำนวนหน้า
- "ดูเพิ่มเติม" โชว์เมื่อยังมีข่าวเก่ากว่าชุดปัจจุบัน; "ย้อนกลับ" โชว์เมื่อ `page > 0`; ถ้ามีหน้าเดียวไม่โชว์ปุ่มเลย
- ปุ่มไว้ใต้รายการด้านขวา ข้อความผ่าน `t.news.more` ("ดูเพิ่มเติม" / "See more") และ `t.news.back` ("ย้อนกลับ" / "Back")
- **ลบกริดข่าว 4 ใบด้านล่าง** (ซ้ำกับรายการที่เลื่อนดูได้) *(ตัดสินใจโดยผู้ช่วย ผู้ใช้ตกลงในภาพรวม)*

## ปล่อยให้ผู้สร้างตัดสินใจ
- ตำแหน่งและหน้าตาปุ่มให้กลมกลืนกับ `linkCls` / ปุ่มเดิม
- วิธีวางปุ่มบนมือถือ (รายการเรียงต่อใต้ข่าวหลัก)
